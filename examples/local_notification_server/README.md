# Local Notification Server

FastAPI service for Firebase Cloud Messaging (FCM). The stream processor sends
violation events here, and this service resolves site subscriptions, user
tokens, and language-specific notification text.

## Responsibilities

- Store and delete device FCM tokens.
- Track token language by user and site.
- Send violation notifications grouped by language.
- Remove invalid tokens reported by Firebase.
- Keep token data in Redis without loading all tokens into memory at once.

## Files

- `app.py`: FastAPI application and Firebase initialisation lifespan.
- `routers.py`: token and notification endpoints.
- `services.py`: Redis token lookup, site subscription, and send orchestration.
- `fcm_service.py`: Firebase Admin SDK wrapper.
- `lang_config.py`: supported languages and warning translations.
- `schemas.py`: request and response models.

## Run

```bash
uvicorn examples.local_notification_server.app:app \
  --host 127.0.0.1 \
  --port 8003 \
  --workers 2
```

## Required Settings

```dotenv
FIREBASE_CRED_PATH=/secure/path/firebase-service-account.json
FCM_API_URL=http://127.0.0.1:8003
DATABASE_URL=postgresql+asyncpg://username:password@127.0.0.1/construction_hazard_detection
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=password
JWT_SECRET_KEY=replace-with-a-long-random-secret
```

Keep the Firebase service-account JSON outside the repository.

## Endpoints

- `POST /store_token`: stores a device token and language for a user.
- `DELETE /delete_token`: removes a device token.
- `POST /send_fcm_notification`: sends one site warning to subscribed users.
- `GET /site_notification_users/{site}`: lists notification subscribers for a
  site.
- `PUT /site_notification_users/{site}`: updates site subscribers.

## Runtime Notes

- Supported language codes are defined in `lang_config.py`.
- Unsupported device languages are rejected instead of silently remapped.
- Redis is used for compact token and subscription state only.
- For violation image delivery, send public image URLs generated by the
  violation records service.
